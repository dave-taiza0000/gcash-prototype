# GCash Prototype — Interactive UI Concept

A fully interactive, single-file mobile app prototype inspired by GCash (Philippines).
Pure HTML/CSS/JS — zero dependencies, zero build step.

> Educational prototype only — not affiliated with GCash / Mynt / Globe.
> No real money or data; everything runs locally in your browser.

## Features
| Category | Included |
|---|---|
| Auth | Login dial pad + 4-digit MPIN |
| Face Verification | Pre-payment scans, failure path, MPIN fallback, thresholds |
| Payments | Send Money, QR scan-to-pay, Pay Bills, Buy Load, Tap to Pay |
| GCredit | Borrow & repay with live utilization ring |
| Money Manager | Donut chart, category budgets, shared budgets |
| Smart Split | Group bills with auto-settlement |
| Transactions | Searchable history, filters, detail view |
| Security | 5 layers, device lock, face settings |

One live wallet balance — every payment updates it and the history in real time.

## Demo login
Any 10-digit mobile number (e.g. 9171234567) + any 4-digit MPIN.

## Run
Open index.html in a browser, or: npx serve .

## Deploy (Netlify)
Drag this folder (or its zip) onto https://app.netlify.com/drop
